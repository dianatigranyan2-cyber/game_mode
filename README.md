# ⛏ Minecraft 1.21 Auto-Miner (Авто-Копатель на Python)

Многофункциональное приложение с графическим интерфейсом на Python для автоматической добычи блоков и копания длинных туннелей в **Minecraft 1.21**.

---

## 🚀 Быстрый запуск

1. Двойным кликом запустите файл **`run.bat`** (он автоматически установит нужные библиотеки и запустит программу).
2. Или выполните в терминале:
   ```cmd
   pip install -r requirements.txt
   python main.py
   ```

---

## 🎮 Горячие клавиши (Hotkeys)

* **`F6`** — **Старт / Пауза** (работает глобально, даже если вы в игре Minecraft).
* **`F7`** или **`ESC`** — **Экстренная Остановка** (мгновенно отпускает все кнопки клавиатуры и мыши).

---

## 🛠 Подготовка в Minecraft 1.21

1. **Возьмите Кирку** в главный слот хотбара (Слот 1).
2. **Факелы**:
   - Возьмите факелы во **вторую руку** (нажмите `F` в инвентаре) **ИЛИ** положите их в Слот 9 хотбара.
   - В настройках приложения выберите соответствующий слот факела.
3. **Еда**:
   - Положите еду в Слот 8 (или любой выбранный слот).
4. **Встаньте в шахте**:
   - Направьте взгляд персонажа ровно **прямо горизонтально** перед собой в сторону будущего туннеля.
5. Нажмите **`▶ СТАРТ`** в программе или горячую клавишу **`F6`**.
6. У вас будет **5 секунд** (по умолчанию), чтобы переключиться на окно Minecraft (`Alt + Tab`).

## ⚡ Режимы Работы

### 1. Туннель 2x1 (Прямой)
Персонаж последовательно:
1. Выкапывает верхний блок перед собой.
2. Выкапывает нижний блок перед собой.
3. Делает шаг вперед.
4. Автоматически ставит факел каждые *N* блоков.
5. При необходимости кушает еду из хотбара.

### 2. АФК Автокликер
Непрерывно зажимает ЛКМ с выбранной задержкой под тип кирки. Удобно для ферм или расчистки территорий.

---

## ⚙️ Задержка под тип кирки

В программе есть готовые пресеты времени на разрушение одного блока камня:
* **Нетеритовая / Алмазная (Эффективность V)**: `0.35` сек.
* **Алмазная кирка**: `0.45` сек.
* **Железная кирка**: `0.60` сек.
* **Каменная кирка**: `0.90` сек.

*Вы можете скорректировать задержку вручную в зависимости от ваших чаров и спешки (Haste).*
